###Análise de Dados de Veículos com Streamlit

Este projeto consiste em uma aplicação interativa desenvolvida com Streamlit para visualização de dados de anúncios de venda de veículos.

##Descrição

A aplicação realiza a leitura de um conjunto de dados armazenado no arquivo vehicles.csv e permite ao usuário explorar informações por meio de gráficos interativos.

##Funcionalidades

A interface disponibiliza dois tipos de visualização:

Histograma da variável odometer
Permite observar a distribuição da quilometragem dos veículos presentes no conjunto de dados.

Gráfico de dispersão entre odometer e price
Possibilita analisar a relação entre a quilometragem e o preço dos veículos.

##Interação

O usuário pode gerar os gráficos por meio de dois botões:

"Criar histograma"

"Criar gráfico de Dispersão"

Os gráficos são exibidos dinamicamente na interface após a interação.
